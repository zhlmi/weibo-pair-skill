# 微博配对

> 你的微博暴露了怎样的你？你和 TA 在数据里合拍吗？——自画像给你自信，配对检验你的自信。

基于微博公开数据的关系分析工具。两个入口，五套视觉输出，全部文案有随机变体池（不会两次一模一样）。

- 🔮 **自画像**（免费，weibo-skill 即可）：七维面相 + 荒诞判词 → 面相诊断书 / 星空罗盘
- 💑 **双人配对**（需 CLI 套餐）：八维匹配 + 缘分指数 → 情侣 · 朋友 · 商务三种方向

## 怎么用

**在 Minis 里**（直接触发 Skill）：

```
帮我跑微博配对
帮我看看我和 @XXX 配不配
```

**命令行**（也可以在 Minis 终端或你自己的环境跑）：

```bash
# 自画像（免费，weibo-skill 即可）
python3 scripts/self-portrait.py

# 双人配对（需 weibo-cli + Token）
python3 scripts/pair.py --other-uid <对方UID> --my-uid <我方UID>
```

完整用法见 **[用户指南](USER-GUIDE.md)**。

## 设计思路

这个 Skill 的出发点很简单：**微博是最诚实的社交数据源**——你发的每一条、转的每一次、凌晨三点敲的字，都在说你是谁、你和谁走得近。面相术和配对术是包装，核心是用数据分析还原那些你自己都没注意到的行为模式。

几个坚持：

- **荒诞但真诚**：面相判词和缘分指数不是"AI 算命"——每一个数据点都是真实的（你的活跃时段、话题偏好、互动频率），判词是数据驱动的镜子，不是玄学
- **反 AI slop**：五个 HTML 输出模板全部从**真实文化母题**出发（相亲角报纸、化验单病历、数据杂志、电影片尾、天文罗盘），手工排版，不用紫渐变/emoji 图标/圆角卡片/Inter 字体——这些 AI 默认审美恰好是"个性"的最大敌人
- **模块化、开源友好**：主流程 pair.py 从 967 行拆成 7 个职责清晰的模块；每个模块一个职责，想改哪块改哪块
- **用户事实优先于算法**：你说"我俩是线下老朋友"→ 跳过极性打折；你说"互关"→ 直接采信。算法永远不替你了解你的关系
