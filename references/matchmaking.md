# 模式二：双人透视（相亲术）

> 你的微博说你是谁，TA 的微博说 TA 是谁。你们配不配？

## 核心逻辑

双人透视 = **两次自画像 + 一次对比矩阵**。不引入新的分析维度——双方各自跑一遍自画像引擎（七维面相），然后对比七维数据，计算匹配度，生成相处建议。

```
自画像引擎(A) → A的七维面相
                              → 对比矩阵 → 匹配度 + 相处建议
自画像引擎(B) → B的七维面相
```

额外数据需求（超出自画像的范围）：
- **双方关注列表交集** → 圈子兼容（对方关注列表不可得时降级，见下）
- **双方互动记录** → 缘分指数

> ⚠️ **圈子兼容降级**：官方 `friendships friends/other` 不存在，对方关注列表无法直接拉取。
> **A×B 配对降级（v1.5.0）**：`--my-uid` 非登录用户时，双方关注列表均不可得（`friends/biz` 仅登录用户），圈子兼容改为**内容圈层近似**（双方微博话题分布余弦），UID 交集归 0，报告标注"API 受限/内容圈层近似"；互关自动检测同理标注"n/a"，用户已知互关用 `--mutual-follow` 确认。
> 使用 `scripts/active-following.py` 降级链路：转发来源 + @账号 → 活跃关注样本 →
> 与己方关注列表做 UID 交集率 / 品类分布相似度，取 max。详见 `data-sources.md`「活跃关注降级」。

## 对比矩阵：七维面相 → 六维匹配

### 额相（发帖时间）→ 作息匹配

| 重叠度 | 判定 | 判词模板 |
|--------|------|---------|
| > 80% | 高度同步 | 「作息同步率 {X}%——你们的生物钟是同一个型号。可以一起熬夜，也可以一起早起。轮着做早餐。」 |
| 50-80% | 部分重叠 | 「作息同步率 {X}%——你们有 {N} 小时的共同清醒时间。利用好重叠时段，剩下的时间各自精彩。」 |
| < 50% | 严重错位 | 「作息同步率 {X}%——一个在凌晨发美食，一个在清晨发跑步。分房睡，或者一方学会说晚安。」 |

### 眼相（话题偏好）→ 兴趣契合

| 相似度 | 判定 | 判词模板 |
|--------|------|---------|
| > 80% | 灵魂共鸣 | 「兴趣契合度 {X}%——你们聊的话题像是复制粘贴。共同话题：{共同话题列表}。小心审美疲劳，偶尔需要新鲜感。」 |
| 50-80% | 有交集 | 「兴趣契合度 {X}%——你们有共同语言，但也有各自的领地。共同话题：{共同话题列表}。分享各自领域的趣事。」 |
| < 50% | 各说各话 | 「兴趣契合度 {X}%——你们的微博像是两个世界。他在聊{A话题}，她在聊{B话题}。约会时各看各的手机，但要坐在一起。」 |

### 气色（情绪基调）→ 性格互补

| 组合 | 判定 | 判词模板 |
|------|------|---------|
| 稳定 + 波动 | 互补型 | 「性格互补度 {X}%——一个是定海神针，一个是过山车。吵架时他讲道理，她翻白眼，然后一起吃火锅。」 |
| 稳定 + 稳定 | 平稳型 | 「性格互补度 {X}%——两个情绪稳定的人在一起，像两杯温水。偶尔需要一些戏剧性。」 |
| 波动 + 波动 | 共振型 | 「性格互补度 {X}%——两个情绪丰富的人在一起，像两团火。准备好纸巾，哭和笑都会加倍。」 |
| 正面 + 负面 | 阳光型 | 「性格互补度 {X}%——一个是小太阳，一个是月亮。别试图治愈对方，阴影也是人格的一部分。」 |

### 口相（互动风格）→ 沟通风格

| 组合 | 判定 | 判词模板 |
|------|------|---------|
| 话唠 + 沉默 | 互补型 | 「沟通风格：话唠×沉默——一个负责说，一个负责听。最佳组合。」 |
| 原创 + 搬运 | 互补型 | 「沟通风格：原创×搬运——一个生产内容，一个分享内容。他写微博，她转微博，然后她评论他写的微博。」 |
| 互动 + 闭口 | 互补型 | 「沟通风格：互动×闭口——一个在评论区活跃，一个在点赞区沉默。闭口的偶尔评论一下就行。」 |
| 话唠 + 话唠 | 竞争型 | 「沟通风格：话唠×话唠——两个广播站在一起，信号互相干扰。轮流说话，或者开个双人播客。」 |

### 骨相（发帖频率）+ 手相（内容特征）→ 创作互补

| 组合 | 判词模板 |
|------|---------|
| 高频 × 低频 | 「他负责刷存在感，她负责偶尔冒泡让人惊喜。频率互补型。」 |
| 原创型 × 搬运型 | 「他负责写，她负责转。这他妈是一个完整的内容生产链。」 |
| 同频同量 | 「两个同频的人——可以合开一个号，也可以互相在评论区抢沙发。」 |

### 眉相（表达习惯）→ 笑点匹配

| 组合 | 判词模板 |
|------|---------|
| 冷面 × 冷面 | 「两个不爱用感叹号的人在一起——他们的聊天记录可能是全世界最像电报的东西。」 |
| 热情 × 冷面 | 「一个负责[哈哈]，一个负责[笑而不语]。互补的幽默。」 |
| 双方同频 | 「你们的幽默在同一个频道——这是最难匹配的维度，恭喜。」 |

## 匹配度计算

```python
def calculate_match_score(profile_a, profile_b):
    scores = {
        "作息匹配":   calc_overlap(profile_a["hour_dist"], profile_b["hour_dist"]),
        "兴趣契合":   cos_sim(profile_a["topic_dist"], profile_b["topic_dist"]),
        "性格互补":   1 - abs(profile_a["sentiment_avg"] - profile_b["sentiment_avg"]),
        "沟通风格":   style_match_table[profile_a["style"]][profile_b["style"]],
        "创作互补":   calc_complement(profile_a["len_avg"], profile_b["len_avg"], profile_a["orig_pct"], profile_b["orig_pct"]),
        "笑点匹配":   calc_punct_similarity(profile_a["punct"], profile_b["punct"]),
        "圈子兼容":   circle_compat_score(profile_a["following"], profile_b["active_following"]),
        "缘分指数":   interaction_score(profile_a["interactions"], profile_b["interactions"]),
    }
    
    weights = {
        "作息匹配": 0.15, "兴趣契合": 0.20, "性格互补": 0.20,
        "沟通风格": 0.15, "创作互补": 0.10, "笑点匹配": 0.05,
        "圈子兼容": 0.05, "缘分指数": 0.10,
    }
    
    return round(sum(scores[k] * weights[k] for k in scores) * 100, 1), scores
```

## 缘分指数（真实互动信号扫描）

> ⚠️ **历史教训（2026-08-05 修复）**：早期版本硬编码 `fate = 0.0  # 无互动`，导致所有配对缘分恒为 0，与事实严重不符（实测某场：对方转发我方 2 次 + 双向转发链共现 8 条，真实缘分 0.95）。缘分必须真计算。

**数据源**：双方已采样的微博列表（`my_posts` / `other_posts`），零额外 API 调用：

| 信号 | 检测方式 | 权重 |
|------|---------|------|
| 直接转发 | `retweeted_status.user.id == 对方UID`（转的是对方原创） | 0.45/次 |
| 回复 | `in_reply_to_user_id == 对方UID` | 0.35/次 |
| 独立 @提及 | 正文中 `@对方昵称`（非 `//@` 转发链格式） | 0.20/次 |
| 转发链共现 | 正文中出现 `//@对方昵称:`（同一条传播链上有对方） | 0.10/条（按微博去重） |
| 互关 | 我方关注列表含对方（`friends/biz` count 上限 20，大概率查不到，尽力而为） | 0.10 |

```
raw = 直接转发×0.45 + 回复×0.35 + @×0.20 + 转发链共现×0.10（技术内容×0.15）+ 互关×0.10
fate = density_to_fate(密度)   # v1.7.0 密度归一，见下

**密度归一（v1.7.0，2026-08-06 提出）**：缘分不再按互动**绝对次数**封顶（少量互动+小样本就 0.95 通胀、样本越大缘分越高、场次不可比），改为：
- 密度 = 加权互动 / min(双方样本) × 100（每百条加权互动次数；分母取双方样本较小者作共同观察窗口，高频博主的日常发博不稀释互动信号）
- 映射：`density_to_fate`——0→0、0.3→0.18、1.2→0.50、5→0.95 封顶（分段线性，技术圈克制转发场景校准）
- 极性打折 / `--polarity-note` 兜底不变，作用于密度分数
- 实测：某场（779×1002 样本，57 转发/90 共现）密度 4.72 → fate 0.917（接近封顶但未满，诚实反映长期窗口）；A×B 场密度 0.19 → 0.114

**转发链共现技术内容加权（v1.7.0）**：互动文本含技术关键词（科技AI/影视影像/行业观察词表）→ 共现权重 0.10 → 0.15（技术圈互转克制，一条技术共现含金量高于泛娱乐十条）。实测某场 90 条共现中 34 条技术内容。

**互动极性（数量 × 质量，2026-08-05 新增；v1.4.3 指向性增强）**：互动数量高不代表关系好——对线/开骂场景互动爆表但内容负面，说"登对"就荒谬了。对每条互动微博文本做正/负面词极性统计：
- 负面词主导（负面占比 ≥50%）→ fate × 0.3，标注「⚠️ 互动偏负面（对线/开骂）——数字高不代表登对」
- 负面占 30-50% → fate × 0.6，标注「互动夹杂摩擦」
- 正面/无互动 → 不打折

**v1.4.3 三项修正（实测场暴露）**：
1. **负面词指向性分析**：负面词与直接称呼（你/您/@）同现才算**关系摩擦**；负面词指向第三方（工作/项目/甲方/行业/体制等 THIRD 词表）是"吐槽日常"，计入 `吐槽第三方` 单独统计、不打折。实测：对方转发链"工作的一些项目都是狗屎"——"狗屎"指向工作而非关系对象，不算摩擦。
2. **NEG 误报黑名单（NEG_FALSE）**：短负面词子串误命中——"服了"命中"太舒服了"、"傻"命中"[傻眼]"表情、"骂"命中"别骂了别骂了"（玩梗求饶）均为误报，黑名单排除。实测某场 8 个"负面词"有 5 个是误报，修复后负面词归 0。
3. **`--polarity-note <文案>` 人工兜底**：用户确认关系事实（如"线下老朋友，认识五六年"）时，跳过极性打折、fate 恢复 raw 封顶，并用该文案覆盖"摩擦"判词（"——互动是日常，不是客套"）。与 `--mutual-follow` 同一哲学：自动检测 + 用户事实优先。
```

**注意**：
- `//@对方昵称` 属于转发链共现，不算独立 @（避免重复计分）
- **技术圈克制转发语义（2026-08-05 用户亲述）**：数字影像/色彩科学等技术圈互转克制、不互捧臭脚，只转核心文献/技术内容，且常为无文字纯转发。因此技术圈场景下"直接转发对方原创"是强认可信号（权重 0.45 已对应），转发链共现含金量也高于社交圈——解读时不要按泛娱乐标准贬低。
- **互关检测**：`friends/biz` count 上限实测 20（--help 写 200 是误导）、`followers/active_list` 仅 TOP20 → 自动检测最多翻 10 页（200 人），翻完未覆盖按 0 计不冤枉；用户已知互关（如与圈内同行互关）用 `--mutual-follow` 参数确认，报告标注"用户确认"。
- 缘分分数进入总分权重 0.10（2026-08-05 从 0.05 上调：互动在多数关系里都重要；interest 同步 0.25→0.20，因它分类器粒度敏感、场间方差极大）。

## 主 Agent 数据完整性审查

双方数据采集完成后、进入分析前。主 Agent 自行检查：

| 检查项 | 合格标准 | 不合格处理 |
|--------|---------|-----------|
| 双方微博样本量 | 各自 ≥ 20 条 | 提示不足，继续但标注 |
| 双方时间跨度 | ≥ 30 天 | 提示太短，继续但标注 |
| 对方关注列表 | 已获取（降级：活跃关注样本 ≥ 10 个 或 内容圈层非空） | 样本不足则圈子兼容标注"低置信度"，仍可计算 |
| 互动数据 | 已查询 | 失败则缘分指数归零 |
| 对方是否为私密 | 微博列表非空 | 为空则停止 |

## 相处建议生成

基于匹配度和各维度得分，生成 3 条荒诞但有洞察的相处建议：

| 匹配度 | 建议风格 |
|--------|---------|
| > 80% | 肯定 + 小提醒：「宇宙说你们该在一起。唯一隐患：太像了会抢着发同一条微博」 |
| 50-80% | 互补 + 具体：「不是天造地设，但正好互补。每周交换一次手机，看看对方的世界」 |
| < 50% | 坦诚 + 幽默：「爱情不是算法。先从互关开始，然后互相屏蔽，再取消屏蔽——这就是现代爱情」 |
