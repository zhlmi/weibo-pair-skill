# 分析引擎

本文档定义微博配对的数据分析维度、评分算法和分类标准。三种模式共享底层分析函数，各自组合不同维度。

## 通用分析函数

### 1. 时间模式分析

**输入**：微博列表中的 `created_at` 字段

**输出**：
```json
{
  "hour_distribution": { "0": 2, "1": 5, "2": 12, ..., "23": 1 },
  "peak_hours": [2, 3, 23],
  "day_distribution": { "Mon": 10, "Tue": 8, ... },
  "is_night_owl": true,
  "is_early_bird": false,
  "posting_regularity": 0.72  // 0-1，发帖时间的规律性
}
```

**判定规则**：
- 夜猫子：22:00-04:00 发帖占比 > 40%
- 早起鸟：06:00-09:00 发帖占比 > 30%
- 规律型：posting_regularity > 0.6
- 随机型：posting_regularity < 0.3

### 2. 话题偏好分析

**输入**：微博列表中的 `text` 字段

**处理**：
1. 提取关键词（名词、动词短语）
2. 按话题领域分类
3. 计算各领域占比

**话题分类体系**（可扩展）：

| 类别 | 关键词示例 |
|------|----------|
| 美食 | 吃、喝、餐厅、做饭、外卖、奶茶、火锅 |
| 旅行 | 旅行、旅游、机票、酒店、景点、出差 |
| 科技 | 手机、电脑、AI、编程、互联网、产品 |
| 娱乐 | 电影、音乐、综艺、明星、追剧 |
| 生活 | 天气、心情、日常、周末、加班、失眠 |
| 工作 | 项目、会议、客户、deadline、KPI |
| 运动 | 跑步、健身、游泳、球、瑜伽 |
| 社会 | 新闻、政策、社会、事件、讨论 |
| 情感 | 恋爱、分手、想念、喜欢、讨厌 |
| 转发抽奖 | 转发、抽奖、锦鲤、福利 |

**输出**：
```json
{
  "topic_distribution": {
    "美食": 0.23,
    "科技": 0.18,
    "生活": 0.35,
    "娱乐": 0.12,
    "其他": 0.12
  },
  "top_topics": ["生活", "美食", "科技"],
  "topic_diversity": 0.78  // 信息熵，0-1
}
```

### 3. 情感基调分析

**输入**：微博列表中的 `text` 字段

**处理**：
1. 基于关键词和表情的情感打分（-1 到 +1）
2. 计算情绪分布

**情感关键词**：
- 正面：开心、哈哈、太好了、棒、喜欢、爱、感谢、期待
- 负面：难过、烦、讨厌、累、崩溃、无语、失望、焦虑
- 中性：（默认）

**输出**：
```json
{
  "average_sentiment": 0.23,  // -1 到 +1
  "sentiment_distribution": {
    "positive": 0.45,
    "neutral": 0.35,
    "negative": 0.20
  },
  "emo_rate": 0.20,  // 负面帖子占比
  "mood_stability": 0.65  // 情绪稳定性，0-1
}
```

### 4. 互动风格分析

**输入**：微博列表（原创 vs 转发比例）、评论数据

**输出**：
```json
{
  "original_rate": 0.67,  // 原创率
  "repost_rate": 0.33,    // 转发率
  "reply_rate": 0.15,     // 回复率（回复数/收到评论数）
  "like_to_comment_ratio": 8.5,  // 点赞/评论比
  "interaction_style": "闭口相"  // 判定结果
}
```

**互动风格判定**：

| 风格 | 条件 | 含义 |
|------|------|------|
| 话痨型 | 日均发帖 > 3 条 | 存在感强，表达欲旺盛 |
| 沉默型 | 日均发帖 < 0.5 条 | 低调，偶尔冒泡 |
| 原创型 | 原创率 > 70% | 创作者倾向 |
| 搬运型 | 转发率 > 70% | 信息整合者 |
| 互动型 | 回复率 > 30% | 喜欢和人交流 |
| 闭口型 | 点赞/评论比 > 10 | 内心戏丰富但不表达 |

### 5. 标点/表情分析

**输入**：微博列表中的 `text` 字段

**输出**：
```json
{
  "exclamation_rate": 0.12,  // 感叹号使用频率
  "ellipsis_rate": 0.08,     // 省略号使用频率
  "emoji_rate": 0.25,        // 表情使用频率
  "question_rate": 0.05,     // 问号使用频率
  "avg_post_length": 45,     // 平均字数
  "punctuation_style": "叹眉" // 判定结果
}
```

**标点风格判定**：

| 风格 | 条件 | 含义 |
|------|------|------|
| 叹眉 | 感叹号频率 > 平均值 2 倍 | 情绪外放，表达欲强 |
| 省眉 | 省略号频率 > 平均值 2 倍 | 留白型，暗示多于明说 |
| 问眉 | 问号频率 > 平均值 2 倍 | 好奇心强，喜欢提问 |
| 平眉 | 各标点均低于平均值 | 冷静理性，情绪内敛 |

## 模式专用分析

### 模式一：自画像维度

| 维度 | 分析函数 | 面相映射 |
|------|---------|---------|
| 发帖时间分布 | 时间模式分析 | 额相 |
| 话题偏好 | 话题偏好分析 | 眼相 |
| 情绪基调 | 情感基调分析 | 气色 |
| 互动风格 | 互动风格分析 | 口相 |
| 发帖频率 | 时间模式分析（日均条数） | 骨相 |
| 原创 vs 转发 | 互动风格分析（original_rate） | 手相 |
| 标点表情 | 标点/表情分析 | 眉相 |

### 模式二：双人透视维度

| 维度 | 分析函数 | 相亲字段 |
|------|---------|---------|
| 作息匹配 | 双方时间模式对比 | 作息匹配度 |
| 兴趣契合 | 双方话题偏好重叠 | 兴趣契合度 |
| 性格互补 | 双方情感基调对比 | 性格互补度 |
| 沟通风格 | 双方互动风格对比 | 沟通风格 |
| 圈子兼容 | 双方关注列表重叠（对方不可得时降级） | 圈子兼容度 |
| 互动频率 | 双方微博中的双向转发 / 回复 / @提及 / 转发链共现（零成本扫描） | 缘分指数 |

**匹配度计算公式**：

```
总匹配度 = (
    作息匹配 × 0.15 +
    兴趣契合 × 0.25 +
    性格互补 × 0.20 +
    沟通风格 × 0.15 +
    圈子兼容 × 0.05 +
    创作互补 × 0.10 +
    笑点匹配 × 0.05 +
    互动频率 × 0.05
) × 100
```

> ⚠️ 权重以 `matchmaking.md` 为准（八维，圈子兼容 0.05）。早期版本此处曾写六维 0.15，已废弃——两文档保持一致。

各维度匹配度计算：

| 维度 | 计算方式 |
|------|---------|
| 作息匹配 | 峰值重合率（用户直觉版）：双方 top3 活跃高峰，误差 ≤1h 全重合（1.0）、1-2h 半重合（0.5）、>2h 不重合（0），得分 = 我方峰值重合分/3，无保底。2026-08-05 两连改：先弃余弦相似度（只认分布形状，同为白天型即使峰值错开 3-5 小时也报高分，某场 0.755 虚高）；再弃重叠面积（用户直觉：峰值对不上就是不同步），最终以「3 个活跃高峰对上几个」为准。该场最终 0.333（只对上 19/20 一个） |
| 兴趣契合 | 话题分布的余弦相似度 |
| 性格互补 | 1 - \|情感基调差\|（差异越大越互补） |
| 沟通风格 | 风格匹配表（见下） |
| 圈子兼容 | 见下方「圈子兼容（降级算法）」 |
| 创作互补 | 0.5 + 0.5×\|原创率差\| + 0.2×min(\|频率差\|/10, 1)，封顶 0.95 |
| 笑点匹配 | 0.5×(1-\|感叹号率差\|) + (冷面/热情互补则 +0.5，否则 +0.2)，封顶 0.9 |
| 互动频率 | min(互动次数 / 30, 1) |

**圈子兼容（降级算法）**：

> 官方 `friendships friends/other` 不存在，无法直接拿对方关注列表。使用 `scripts/active-following.py` 的降级链路：

```
a. UID 硬交集率 = |我方关注列表 ∩ 对方活跃关注样本| / |对方活跃关注样本|
b. 品类相似度 = 我方关注列表品类分布 与 对方活跃关注品类分布的余弦相似度
圈子兼容得分 = max(a, b)，并标注"降级估算"
```

- 我方关注列表：`friends/biz --count 20`（注意实测 count 上限 20，需翻页；description 字段完整，归类置信度高）
- 对方活跃关注样本：转发来源 + @账号（`other` 接口 description 被裁剪 → 归类置信度低，见 data-sources.md「已知限制」）
- 原创型博主样本小时：a 可能为 0，以 b 兜底；两者都缺时标注"数据缺失"并按 0 计，权重归一化剔除

**沟通风格匹配表**：

| 我的风格 | 对方风格 | 匹配度 |
|---------|---------|--------|
| 话痨型 | 话痨型 | 0.6（容易抢话） |
| 话痨型 | 沉默型 | 0.8（互补） |
| 原创型 | 搬运型 | 0.7（互补） |
| 原创型 | 原创型 | 0.5（容易撞车） |
| 互动型 | 闭口型 | 0.7（互补） |
| 互动型 | 互动型 | 0.9（聊得来） |

### 模式三：关注列表定律维度

| 维度 | 分析内容 | 输出 |
|------|---------|------|
| 品类分布 | 关注账号的话题领域 | 各品类占比 |
| 认证类型 | verified 状态 | 机构/个人/混合 |
| 粉丝量级 | followers_count 分布 | 头部/腰部/尾部占比 |
| 活跃度 | 最近发帖时间 | 活跃/僵尸占比 |
| 情绪倾向 | 关注账号的内容情感 | 整体情绪标签 |
| 信息多样性 | 品类分布的信息熵 | 多样性评分 |

**品类分类**（基于账号简介和内容）：

| 品类 | 特征关键词 |
|------|----------|
| 军事 | 军事、国防、武器、战略、战机、导弹 |
| 财经 | 股票、基金、投资、理财、A股、牛市 |
| 时政 | 政策、两会、国际、外交、评论 |
| 科技 | 科技、数码、互联网、AI、产品 |
| 娱乐 | 明星、综艺、影视、八卦、追星 |
| 生活 | 美食、旅行、穿搭、家居、日常 |
| 媒体 | 新闻、日报、晚报、时报、网 |
| 知识 | 科普、历史、文化、教育、读书 |
| 搞笑 | 搞笑、段子、沙雕、哈哈哈 |
| 情感 | 情感、心理、两性、恋爱 |

**成分标签生成规则**：

| 成分 | 条件 | 标签 |
|------|------|------|
| 军事财经型 | 军事+财经占比 > 50% | 「战略家」 |
| 娱乐追星型 | 娱乐占比 > 40% | 「饭圈居民」 |
| 科技极客型 | 科技占比 > 30% | 「数字原住民」 |

| 信息茧房型 | 前 2 品类占比 > 70% | 「茧房居民」 |
| 杂食型 | 品类分布均匀，最大 < 25% | 「杂食动物」 |
