# 视觉输出规范

本文档定义微博配对三种模式的视觉风格、配色、字体和 HTML 模板结构。

## 通用规范

- 所有输出为自包含 HTML 文件，支持亮/暗主题切换
- 默认亮色主题，暗色主题通过 CSS 变量切换
- 支持打印（@media print 强制亮色）
- 图片使用内联 SVG 或 data URI，不依赖外部资源
- 字体：中文使用系统字体栈（-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif），英文使用 Georgia / serif

## HTML 模板实现

### 技术栈

- 纯 HTML + CSS，无外部依赖
- CSS 变量支持亮/暗主题切换
- @media print 强制亮色
- 响应式设计，支持移动端查看
- 可选：内联 SVG 装饰元素

### 文件命名

```
templates/
├── self-portrait.html      # 自画像模板
├── matchmaking.html        # 相亲术模板
└── following-law.html      # 关注列表定律模板
```

### 数据注入方式

模板中使用 `{{变量名}}` 占位符，由 Python 脚本替换为实际数据。

示例：
```html
<div class="nickname">{{nickname}}</div>
<div class="score">{{total_score}}</div>
<div class="bar" style="width: {{dimension_score}}%"></div>
```
