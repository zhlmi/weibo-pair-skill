# 模式一：自画像（相面术）

> 你的微博就是你的面相。

## 面相术语映射体系

### 额相（思维方式）—— 基于发帖时间分布

| 术语 | 条件 | 判词模板 |
|------|------|---------|
| 子时额 | 22:00-04:00 发帖 > 40% | 「{昵称}的额相属子时型，主思维跳跃，灵感多于执行。凌晨三点常有顿悟，次日中午全部忘记。建议：睡前备好笔记本，或者接受自己是夜行动物」 |
| 卯时额 | 06:00-09:00 发帖 > 30% | 「{昵称}的额相属卯时型，主自律极强，日程表精确到分钟。朋友圈里最早的鸟，但可能错过了所有深夜灵感。建议：偶尔允许自己赖床」 |
| 散时额 | 发帖时间分布均匀 | 「{昵称}的额相属散时型，主思维自由，不受时间束缚。可能是自由职业者，也可能是失眠患者。建议：确认一下到底是哪种」 |
| 午时额 | 11:00-14:00 发帖 > 30% | 「{昵称}的额相属午时型，主午休时间是创作高峰期。上班摸鱼的灵魂诗人，午饭后的灵感喷泉。建议：和老板谈谈把午休延长到两小时」 |

## 总判词生成规则

从七个维度各选一个术语，组合成总判词。格式：

```
「{昵称}的数字面相为：{额相}、{眼相}、{气色}、{口相}、{骨相}、{手相}、{眉相}。

综合判语：{基于维度组合的总结性判断}。

运势建议：{一条荒诞但有洞察的建议}。」
```

**维度组合示例**：

| 组合 | 综合判语 |
|------|---------|
| 子时额 + 美食眼 + 闭口相 | 「深夜美食沉默者——你用味蕾思考，用沉默表达，用点赞代替千言万语。你的灵魂在凌晨三点的厨房里最自由」 |
| 卯时额 + 科技眼 + 话唠口 | 「早起科技广播员——你比太阳起得早，比AI说得快。你的朋友圈是科技早报，你的微博是行业风向标」 |
| 散时额 + 散光眼 + 混合手 | 「万能杂食型——你是信息时代的游牧民族，在各个领域之间自由迁徙。不适合深耕，但适合做跨界桥梁」 |
